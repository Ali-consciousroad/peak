📋 Package Layer Legend

Frontend Layer: UI Components, Pages, User Interface
API Layer: REST Endpoints, HTTP Routes
Business Logic: Core Services, Custom Hooks
Data Access: Database Schema, Migrations
External Services: Third-party Integrations
Configuration: Build & Config Files

🔗 Key Dependencies

  • Frontend → API: HTTP requests for data fetching
  • API → Business Logic: Service layer calls and validation
  • Business Logic → Data Access: Database operations via Prisma
  • All Layers → External Services: Authentication, hosting, database
